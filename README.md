
# QA Automation Engineer - Mobile Challenge (Stable Execution)

## Visão Geral
Projeto de automação mobile com foco em arquitetura e estabilidade.

## Estratégia
Os testes são executados em modo simulado (mock) para garantir execução estável
em qualquer ambiente.

## Tecnologias
- JavaScript
- WebdriverIO
- Mocha
- Chai

## Execução
npm install
npm test

## Cenários
- Login / Cadastro
- Navegação
- Formulários
- Validações de erro

## Observação
Execução real via Appium pode ser habilitada futuramente.
